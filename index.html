Novel · Pipeline

五段流水线,一条线跑到底

改编大纲收敛结构,剧本、场景、角色三者同步迭代,分镜只做输出不做新决定。

01
改编大纲NOVEL-OUTLINE
把小说改编成短剧大纲五件套:改编说明、人物表、爽点表、分集梗概、资产清单(含叙事道具表),支持已有大纲的体检模式。
14 道质量门
02
角色设定NOVEL-CHARACTERS
把大纲定下的角色做成角色设定集:人物画像、形象提示词、音色提示词、角色设定图,吃 outline.json 预填角色表。
脚本检查
03
美术设定NOVEL-ART
出场景 + 叙事道具的美术设定集:一致性锚点、光照与状态变体、尺度参照、无人无手白底提示词。
11 道质量门
04
剧本NOVEL-SCRIPT
场次 + 节拍流,逐集时长按语速确定性折算,台词本按角色聚合带音色提示词,直接对接 TTS。
10 道质量门
05
分镜NOVEL-STORYBOARD
段(≤15 秒)→ 分镜(2–5 秒硬门)→ 分镜图,H3 提示词逐字对账,export 一键出投产包。
17 道质量门

Novel · Single Page

五份报告,合成一张单页

组装器,不是独立 skill

不 import 任何 skill 的代码,而是调各自的 render --html 拿产物再拼装。五个 skill 一行不改、各自独立可跑。有哪几段就出哪几个面板,不报错。

  • 01样式串味 — 五份报告 13 个同名不同义的类名,给每条选择器加作用域前缀。
  • 02脚本串味 — 每份脚本套一层作用域代理,五个导出按钮互不干扰。
  • 03图片路径 — 按输出文件位置重算相对路径,图不会静默变占位。

# 合成单页报告
node scripts/report.mjs \
  --from <demo目录> \
  --out report.html

# 只跑了角色一段?就只有一个面板
# 数字键 1–5 切面板,#pane-script 深链直达

# 92 项断言自测,不起浏览器
node scripts/report-selftest.mjs
Novel · Install

一条命令,软链即装

自动检测本机装了 Claude Code 还是 codex,软链过去——git pull 之后立刻生效,不用重装。

克隆即用

skill 的脚本只用标准库,没有 npm 依赖,不需要 install。

git clone https://github.com/lentt449-design/supreme-bassoon.git
cd supreme-bassoon
./scripts/install.sh

按需安装

只装某一个、只装到 codex、或取消软链。

./scripts/install.sh novel-characters
./scripts/install.sh --codex
./scripts/install.sh --uninstall

跑一遍自测

每个 skill 必带 selftest,不调模型、不花额度,1 秒跑完。

for f in skills/*/scripts/selftest.mjs
do
  node "$f"
done
